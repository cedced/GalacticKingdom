# Glossary

Use these exact terms in code identifiers, data files, and UI copy.

| Term | Meaning |
|---|---|
| Galaxy | The full set of star systems and the warp lanes connecting them. One galaxy per shard. |
| Shard | One running world with its own galaxy seed and database. |
| System | A star system. One instance on the server; the unit of networking rooms and PvP rules. |
| Warp lane | An edge between two systems. Traversed via a warp gate. |
| Warp gate | The object in a system you fly into to jump along a lane. |
| Warp fuel | Per-character resource that accrues in real time and is spent on jumps, landings, and docking. |
| Body | Anything orbiting the star: planet, moon, asteroid field, derelict. |
| Port | A small station that buys and sells commodities. Cannot sell ships. |
| Starbase | A large station that sells ships, hulls, weapons, and shields. Rare. |
| Colony | A planet owned by a player or corporation. |
| Capture | Taking ownership of a colony by defeating its defenses and landing. |
| Safe space | Systems patrolled by the Concord (our stand-in for the U.N.). PvP disabled, NPC police respond to aggression. |
| Lawless space | Everything else. PvP enabled. |
| Shields | Hit points. Do not regenerate. Purchased at ports and starbases. |
| Energy | Weapon and thruster budget. Regenerates. |
| Hull | Ship class. Defines cargo slots, hardpoints, mass, base energy. |
| Hardpoint | A slot on a hull that holds one weapon or module. |
| Commodity | A tradeable good with a base price and supply/demand curves per port. |
| Faction | A named NPC power with territory, reputation, and relationships. |
| Standing | A player's reputation with one faction, -100 to 100. |
| Corporation | A player-run group. Shares colonies and a chat channel. |
| Quest | A generated, time-bounded objective offered to one player or corporation. |
| Event | A galaxy-wide or system-wide condition generated from world state (blockade, plague, gold rush). |
| Tick | One server simulation step, 50 ms (20 Hz). |
| Biome | Planet type. Sets growth tendency, resource profile, pollution rate, and unique building. |
| Government | Colony policy choice trading off morale, growth, and production. |
| Morale | Colony happiness. Drives XP yield and tolerable tax rate. |
| Pollution | Per-colony buildup from production. Costs credits to clean; hurts growth if ignored. |
| Sleeper | A logged-out player's ship left in the world. Attackable outside safe space and ports. |
| Rebang | Shard mode that resets on a schedule and awards medals to top ranks. |
| Permaverse | Shard mode that never resets. |
| Experience | Rank score. From kills, discovery, missions, haggling, and colonist morale over time. |
| Artifact | Rare alien item found on planets, including uncolonizable ones. Some are ship modules. |
| Paradise world | One of a few no-pollution, all-resource planets per shard. Endgame contest targets. |
| Enter mode | Input state where colliding with a port, gate, or planet triggers docking, jumping, or landing. |
